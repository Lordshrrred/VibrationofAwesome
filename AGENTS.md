# Vibration of Awesome — Codex Instructions

This repository is the canonical code/content repository for VibrationOfAwesome.com and the Vibration of Awesome project.

Before making meaningful changes:

1. Read `BMO_CONTEXT.md`.
2. Inspect the existing repository, architecture, documentation, and implementation.
3. Treat the current user request as higher priority than older context.
4. Do not assume something needs to be rebuilt simply because it could be redesigned.
5. Preserve working behavior unless the requested task requires changing it.

## Core Working Rules

- Inspect before rewriting.
- Prefer incremental, testable changes.
- Preserve existing architecture when it is sound.
- Do not invent product claims, achievements, testimonials, partnerships, statistics, or history.
- Do not turn Vibration of Awesome into generic wellness, motivational, spiritual, or AI-SaaS branding.
- Avoid generic corporate copy and generic startup language.
- Protect privacy.
- Never commit secrets, credentials, API keys, tokens, personal information, or unnecessary identifying metadata.
- Keep public-facing content focused on the project rather than the creator's private life.
- Validate meaningful changes before considering the task complete.
- Update durable documentation when architectural or canonical project knowledge materially changes.

## Brand North Star

Vibration of Awesome exists to help people cultivate a more alive, creative, connected, purposeful, authentic way of being.

It is not about pretending everything is awesome.

Read `BMO_CONTEXT.md` for the complete project context.
