# Module: Site, hosting, redirects, and static pages

Read this before touching `layouts/`, `vercel.json`, `api/`, static pages, nav, or social metadata. Public-facing truth about what the site offers: `docs/voa-public-site-truth.md`.

## Stack

- **Hugo** renders `content/posts/*.md` with `layouts/` (`hugo.toml` sets goldmark `unsafe = true`). Most blog content is standalone HTML under `static/`, not Hugo content. Dev: `hugo server -D` (http://localhost:1313).
- **Vercel** serves the static site and serverless functions (`/api/*`: AURA chat, Stripe checkout/verification, backlink verification, editor login/save). Auto-deploys on push to `main`. Project `prj_guDrrflKSY3FwVbmFMNyQRZyTwI9`, org `team_YNP01D3hmpGWSbkZOSV8l0O0`. `cleanUrls: true`.
- **Cloudflare**: DNS/SSL; apex and `www` route to Vercel. **GitHub** is source control only; GitHub Pages is retired.
- **AURA** (`api/chat.js`, ESM, Sonnet 4.6 via `callAnthropicWithRetry()`): UI at `/aura/`. Stripe: `api/create-checkout.js`, `api/verify-subscription.js`; setup via `node scripts/setup-stripe.js`.
- **Post editor**: VOA Post Studio (`api/editor-login.js` + `api/editor-save.js`). `static/admin/` (Decap/Netlify CMS) is legacy: don't delete it, don't prioritize it; if you touch it, fix `site_domain` in `static/admin/config.yml` to the Vercel URL.

## Deployment health

Every Vercel build runs `scripts/write-build-info.js` first (`vercel.json` `buildCommand`), which stamps the deployed commit into `/build-info.json` (gitignored; exists only in deployed builds). `scripts/deployment-health.js` reads that from the main site and the mailer (falling back to `vercel inspect` if present), then uses `classify()` from `vercel-ignore-build.js` to decide whether anything since the deployed commit should have triggered a deploy. So "Current" means "nothing deployable is pending", not "serving literally the latest commit" (most commits are ops data Vercel skips on purpose). `syndication-health.yml` refreshes and commits `static/_data/deployment-health.json` every 12h; the dashboard card shows the reason and flags checks older than 2 days.
